경사하강법 초기 설정하기

  • 경사하강법을 시작하기 위한 초기 변수 설정
    • 변수: 학습률, 시작점의 x좌표, 반복횟수, 경사하강법의 진행을 보기 위한 구
from vpython import *
scene = canvas(title = "Gradient Descent on y=x^2", background=color.white)

scene.camera.pos = vec(0, 2, 10)
scene.camera.axis = vec(0, 2, -10)

curve_points = []
for n in range(-300, 301):
    i = n / 10
    curve_points.append(vec(i, i**2, 0))

parabola = curve(pos=curve_points, color=color.blue)

learning_rate = 0.1 # 학습률
x_start = 6 # 시작점
ball = sphere(pos=vec(x_start, x_start**2, 0), radius=0.4, color=color.cyan)
step_num = 100 # 반복횟수

label(pos=vec(-5, 5, 0), text=f"learning rate: {learning_rate}")

import time
time.sleep(10)
  • 경사하강법의 기본원리 : 함수의 기울기 계산 → 기울기에 따라 이동
    • 얼마만큼 이동할 것인지 한 스텝의 이동 크기를 결정하는 주요 변수가 학습률(learning rate)

미분 및 경사하강법 함수 정의하기

  • 매개변수로 함수 f와 x를 받아 x좌표에서 접하는 기울기를 반환하는 함수
def f(x):
    return x**2

def numerical_diff(f, x):
    h = 0.0001
    return (f(x + h) - f(x - h)) / (2 * h)
  • 경사하강법 한 번 시행 후 새로운 x좌표를 구하기 위한 함수
def gradient_descent(x, learning_rate):
    gradient = numerical_diff(f, x)
    x_new = x - learning_rate * gradient
    return x_new

경사하강법 수행하기

  • 코드 구성
1. 함수 gradient_descent()로 현재의 경사를 반영한 공의 다음 x좌표 구하기(x_new)
2. 새로 구한 좌표(x_new, f(x_new), 0)에 자취용 구로 흔적 남기기
3. 기존 공을 새로운 좌표 (x_new, f(x_new), 0)에 옮기기
4. 1부터 이과정 반복
for i in range(step_num):
    rate(2)
    x_new=gradient_descent(ball.pos.x, learning_rate)
    ball_new_pos = vec(x_new, x_new**2, 0)
    sphere(pos=ball_new_pos, radius=0.4, color=color.red, opacity=0.7)
    ball.pos = ball_new_pos

print(f"최솟값은 x = {round(ball.pos.x, 2)}, y = {round(ball.pos.y, 2)} 입니다.")
