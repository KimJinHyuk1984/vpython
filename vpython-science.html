과학 시뮬레이션(물체의 운동)

운동의 기초 개념 이해하기

  • 운동 : 물체의 위치가 시간이 지남에 따라 변하는 것
    • 위치(position) : 물체가 공간의 어느 지점에 있는지를 나타냄. 좌표계 사용
    • 속도(velocity) : 물체가 얼마나 빠르게 이동하는가. 속도는 벡터
      • 일반적으로 오브젝트 안에 변수를 생성해서 속도를 나타냄
        # 처음에 vec(2,0,0)으로 설정된 속도를 vec(3,0,0)으로 바꾸기

ball = sphere(pos=vec(3, 0, 0), v = vec(2, 0, 0))
ball.v = vec(3, 0, 0)
    • 가속도(acceleration) : 속도가 시간에 따라 얼마나 빠르게 변하는지를 나타냄. 가속도도 벡터
      • 가속도를 이용해서 물체의 속도를 시간에 따라 업데이트하면 물체가 점점 더 빠르게(혹은 느리게 움직이는 모습을 시뮬레이션 할 수 있음

등속도 운동

1. 반지름이 0.5인 보라색 공은 (-9, 0, 0)에 위치한다
2. 공은 vec(2, 0, 0)의 속도를 갖는다.
3. 공은 x좌표가 3미만 일 때까지 계속해서 2의 속도로 등속도 운동을 한다.
4. 지면을 나타내는 녹색 직육면체를 만든다(사실적으로 표현하기 위해 지면을 가로 20, 세로 10, 높이 1)
from vpython import *

canvas(background=color.white)

# 초기설정
ground = box(pos= vec(0, -1, 0), size=vec(20, 1, 5), color=color.green)
ball = sphere(pos=vec(-9, 0, 0), radius=0.5, color=color.purple, v=vec(2, 0, 0))
dt = 1 # 시간 변화량(단위: 초)

import time
time.sleep(10)

  • 공은 x좌표가 3미만일 때까지 2의 등속도 운동을 해야한다.
while ball.pos.x < 3:
	rate(1)
	ball.pos = ball.pos + ball.v*dt
  • 실행결과를 보면 공이 순간이동을 하는 것 처럼 보인다.
    • 이유는 시간 변화량(dt = 1)의 간격이 너무 길기 때문
    • 1초에 공이 2씩 움직이는 운동을 유지하기 위해 dt는 0.01로, 화면 업데이트 횟수인 rate()는 초당 100회 업데이트로 설정
from vpython import *

canvas(background=color.white)

# 초기설정
ground = box(pos= vec(0, -1, 0), size=vec(20, 1, 5), color=color.green)
ball = sphere(pos=vec(-9, 0, 0), radius=0.5, color=color.purple, v=vec(2, 0, 0))
dt = 0.01 # 시간 변화량(단위: 초)

while ball.pos.x < 3:
	rate(100)
	ball.pos = ball.pos + ball.v*dt

import time
time.sleep(10)

등가속도 운동

  • 등가속도 운동: 가속도가 일정한 운동. 즉, 가속도가 일정하기 때문에 속도는 점점 변화한다.
  • 등속도 운동에서 가속도가 2인 것으로 변경하자
    1. 변수 a에 가속도 저장
2. "나중 속도 = 이전속도 + 가속도 * 걸린 시간" 이므로 0.01초마다 ball.v를 갱신하는 코드만들자
from vpython import *

canvas(background=color.white)

# 초기설정
ground = box(pos= vec(0, -1, 0), size=vec(20, 1, 5), color=color.green)
ball = sphere(pos=vec(-9, 0, 0), radius=0.5, color=color.purple, v=vec(2, 0, 0))
a = vec(2, 0, 0)
dt = 0.01

while ball.pos.x < 3:
	rate(100)
	ball.pos = ball.pos + ball.v*dt # 위치 업데이트
	ball.v = ball.v + a*dt # 속도 업데이트

import time
time.sleep(10)

두 가지 운동을 비교하기

  • 두 물체의 운동을 비교하기 위해 두 갱의 공을 만들어 x좌표가 3이되면 종료되는 시뮬레이션 만들기
1. 캔버스 두 개 생성하기
2. ball1은 캔버스 c1, ball2는 캔버스 c2
3. 두 공이 동시에 움직여야 하기 때문에 반복문 안에 각각의 운동 수식을 동시에 작성하기
from vpython import *

c1 = canvas(background=color.white, height=300)
c2 = canvas(background=color.white, height=300)

# 1번 공 초기설정
ground1 = box(canvas=c1,pos= vec(0, -1, 0), size=vec(20, 1, 5), color=color.green)
ball1 = sphere(canvas=c1,pos=vec(-9, 0, 0), radius=0.5, color=color.purple, v=vec(2, 0, 0))
dt = 0.01

# 2번 공 초기설정
ground2 = box(canvas=c2,pos= vec(0, -1, 0), size=vec(20, 1, 5), color=color.green)
ball2 = sphere(canvas=c2,pos=vec(-9, 0, 0), radius=0.5, color=color.purple, v=vec(2, 0, 0))
a = vec(2, 0, 0)


while ball1.pos.x < 3 and ball2.pos.x < 3:
	rate(100)
	# 1번 공(등속도)
	ball1.pos = ball1.pos + ball1.v*dt # 위치 업데이트

  # 2번 공(등가속도)
	ball2.pos = ball2.pos + ball2.v*dt # 위치 업데이트
	ball2.v = ball2.v + a*dt # 속도 업데이트

import time
time.sleep(10)

등속도운동과 등가속도 운동을 그래프로 표현하기

from vpython import *

c1 = canvas(background=color.white, height=300)
c2 = canvas(background=color.white, height=300)

# 1번 공 초기설정
ground1 = box(canvas=c1,pos= vec(0, -1, 0), size=vec(20, 1, 5), color=color.green)
ball1 = sphere(canvas=c1,pos=vec(-9, 0, 0), radius=0.5, color=color.purple, v=vec(2, 0, 0))
dt = 0.01

# 2번 공 초기설정
ground2 = box(canvas=c2,pos= vec(0, -1, 0), size=vec(20, 1, 5), color=color.green)
ball2 = sphere(canvas=c2,pos=vec(-9, 0, 0), radius=0.5, color=color.purple, v=vec(2, 0, 0))
a = vec(2, 0, 0)

# 그래프 기본 설정
result_graph = graph(title="시간에 따른 공의 위치 변화", xtitle="시간", ytitle="위치", width=600, height=300)

# ball 1 에 대한 그래프
ball1_curve = gcurve(graph=result_graph, color=color.red, label="Ball 1 Position")
# ball 2 에 대한 그래프
ball2_curve = gcurve(graph=result_graph, color=color.blue, label="Ball 2 Position")

time = 0

while ball1.pos.x < 3 and ball2.pos.x < 3:
	rate(100)
	# 1번 공(등속도)
	ball1.pos = ball1.pos + ball1.v*dt # 위치 업데이트
	ball1_curve.plot(time, ball1.pos.x) # 그래프에 위치 업데이트

    # 2번 공(등가속도)
	ball2.pos = ball2.pos + ball2.v*dt # 위치 업데이트
	ball2.v = ball2.v + a*dt # 속도 업데이트
	ball2_curve.plot(time, ball2.pos.x) # 그래프에 위치 업데이트

	time += dt



import time
time.sleep(10)

자유낙하운동

  • 중력가속도 : 중력에 의해 운동하는 물체가 갖는 가속도
  • 자유낙하운동은 등가속도 운동임
from vpython import *

canvas(background=color.white)

ground = box(pos=vector(0, -0.5, 0), size=vector(30, 1, 10), color=color.black)

# 공
ball = sphere(pos=vector(0, 20, 0), radius=1, color=color.cyan, make_trail=True)

# 중력가속도
g = vec(0, -9.8, 0)

# 공의 초기 속도
ball.v = vec(0, 0, 0)
dt = 0.01

# 공의 움직임 업데이트
while ball.pos.y > 0:
    rate(100)
    ball.pos += ball.v*dt
    ball.v += g*dt
